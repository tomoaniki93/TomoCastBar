# TomoCastbar

TomoCastbar is a standalone castbar addon for World of Warcraft Retail. It replaces Blizzard castbars with configurable bars for Player, Target, Focus, Boss and Arena units.

## 3.2.0 — Arcane Pulse

Version 3.2.0 refreshes the complete visual language while preserving the proven 3.1.3 feature set. The configuration panel now uses a larger, cleaner navigation shell with stronger active states and a visible scrollbar. Castbars use a low-noise glass treatment, ice-cyan information accents and electric-violet highlights designed to stay readable in Mythic+, raid and PvP combat.

### Main features
- Player, Target, Focus, Boss and Arena castbars
- Casts, channels and Evoker empowered stages
- Channel tick markers
- Per-cast player latency overlay
- GCD spark
- Interrupt feedback
- Class colors and configurable cast-state colors
- Layout mode with grid and movers
- Named profiles with specialization assignment
- LibSharedMedia support
- 8 localizations

### Commands
- `/tcb` — open configuration
- `/tcb layout` — open layout mode
- `/tcb reset` — reset settings
- `/tcb help` — list commands
